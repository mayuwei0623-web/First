猫咪梳毛挑战 · 首版功能规则 v0.8 精简版

只保留程序实现必须知道的规则、参数、流程和验收标准。

一关无尽 拖动梳毛 单次拖动一次掉毛 显示当前积分 隐藏连击倍率 无限广告复活

0. 首版结论

玩家在猫咪区域按下，梳子出现在点击位置；拖动到猫咪身体区域并达到距离阈值后，触发一次梳毛、掉毛、加分。同一次拖动只计一次，但不限制继续拖动。猫咪回头后，超过反应时间还触发梳毛就失败；失败后可无限看广告复活。

必须做

  • 拖动梳毛，不是点击梳毛。
  • 一次拖动最多计一次。
  • 触发后继续拖动仍跟手，只是不再掉毛。
  • 局内固定位置显示当前积分。
  • 复活次数无限，每次看广告。

不做

  • 不做关卡、通关、金币、商城、养成。
  • 不在毛发位置显示本次加分。
  • 不展示连击、倍率。
  • 不展示玩家手，只展示梳子。

1. 核心状态

状态 字段值 说明 有效梳毛结果
放松 Idle 猫咪没回头。 成功梳毛，加分，掉毛。
警觉 Alert 猫咪回头。 未超过 X 秒可成功；超过 X 秒则被发现。
发现 Discovered 猫咪发怒。 本局中断，弹复活。
复活过渡 Reviving 广告完成后的安全恢复。 短暂锁输入。
结束 GameOver 玩家放弃复活或重开。 不处理梳毛。
Idle→Alert→Idle
Alert 超过 X 秒+触发梳毛→Discovered→复活弹窗

2. 输入与区域规则

2.1 两个区域

区域 字段 规则
可点击拖动区域 catInteractArea 框住猫咪整体的方形/矩形区域。只有在这里按下，才出现梳子并开始拖动。
可掉毛区域 catGroomableArea 猫咪身体区域。只有梳子在这里移动，才累计有效梳毛距离。

2.2 单次拖动

行为 规则
按下 若在 catInteractArea 内，梳子出现在点击位置。
拖动 梳子跟随手指移动。
在身体区域拖够距离 触发一次有效梳毛。
同一次拖动继续移动 梳子继续跟手，但不再计分、不再掉毛。
再次梳毛 必须松开，再重新按下拖动。
onPointerDown(pos): if !inside(catInteractArea, pos): return isDragging = true hasGroomedThisDrag = false combPosition = pos dragDistance = 0 showCombAt(pos) onPointerMove(pos): if !isDragging or isInputLocked: return moveCombTo(pos) if hasGroomedThisDrag: return # 继续跟手，但不再掉毛 if inside(catGroomableArea, pos): dragDistance += distance(pos, lastPointerPosition) if dragDistance >= groomDistanceThreshold: hasGroomedThisDrag = true tryTriggerGroom() else: dragDistance = 0 onPointerUp(): isDragging = false hasGroomedThisDrag = false dragDistance = 0

4. 警觉与失败

规则 说明
警觉 猫咪回头，状态变为 Alert。
发现 猫咪发怒，状态变为 Discovered。
发现判定 Alert 状态持续超过 discoverDelayAfterAlert 后，玩家再次触发有效梳毛，则失败。

tryTriggerGroom(): if catState == "Idle": applySuccessfulGroom() return if catState == "Alert": if alertElapsedTime >= discoverDelayAfterAlert: triggerDiscovered() else: applySuccessfulGroom() return

9. 完整流程

9.1 正常梳毛

按下猫咪交互区域→ 梳子出现在点击位置→ 拖动梳子→ 进入身体掉毛区域→ 累计拖动距离达到 X→ 触发一次梳毛→ 当前积分增加→ 生成毛发→ 继续拖动只跟手→ 松开后可再次拖动

9.2 警觉安全

猫咪回头→ 进入 Alert→ 玩家不触发梳毛→ 警觉时间结束→ 回到 Idle

9.3 警觉失败

猫咪回头→ Alert 持续超过 X 秒→ 玩家再次拖动达标→ 触发梳毛判定→ 猫咪发怒→ 弹出复活

9.4 复活继续

点击看广告继续→ 广告完成→ 保留积分→ 清空连击→ 回到 Idle→ 1 秒安全期→ 继续玩

10. 验收标准

  • 只能在猫咪交互区域内按下开始拖动。
  • 按下后梳子出现在点击位置，拖动时跟手。
  • 只有在猫咪身体掉毛区域内拖够距离，才触发梳毛。
  • 一次拖动只触发一次掉毛和加分。
  • 触发后继续拖动不能卡手，但不再掉毛、不再加分。
  • 松开后重新拖动，才能再次掉毛。
  • 当前积分只在一个固定位置展示。
  • 不展示本次加分、连击、倍率。
  • 连击、倍率、掉毛数量一比一，最高 10。
  • 超过 2 秒没有成功梳毛，连击重置。
  • 猫咪回头后，超过 X 秒再次触发梳毛会失败。
  • 失败后可无限看广告复活，复活保留积分、清空连击。
首版目标：玩家清楚理解“拖一下梳一次”，在猫咪回头时产生“要不要再拖一下”的犹豫，并愿意通过广告继续当前积分。
